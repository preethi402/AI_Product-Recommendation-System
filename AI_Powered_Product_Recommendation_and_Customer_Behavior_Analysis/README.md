AI-Powered Product Recommendation and Customer Behavior Analysis

Project Overview

This project recommends products to customers based on their previous interactions and preferences.

It also provides a dashboard to analyze customer behavior and product popularity.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

Features

- Displays available products.
- Recommends products based on customer preferences.
- Analyzes customer interactions.
- Displays popular products using charts.
- Provides customer analytics.

Project Files

- "app.py" – Main application and dashboard.
- "model.py" – Product recommendation model.
- "products.csv" – Product dataset.
- "customer_data.csv" – Customer interaction dataset.

How to Run

1. Install Python.
2. Install the required libraries.
3. Open the project folder in VS Code.
4. Run the following command:

python -m streamlit run app.py
