AI Product Recommendation System

Project Description

This project recommends products to customers based on their previous ratings and preferences.

It uses Python, Pandas, and machine learning techniques to analyze customer behavior and recommend suitable products.

Features

- Display available products and prices
- Recommend products based on customer preferences
- Analyze customer ratings
- Display popular products
- Visualize customer behavior using charts

Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit

How to Run the Project

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Install the required libraries:
   
   pip install pandas scikit-learn streamlit

5. Run the application:
   
   python -m streamlit run app.py

6. Open the local URL displayed in the terminal.

Project Files

- "app.py" – Streamlit application and dashboard
- "model.py" – Product recommendation model
- "products.csv" – Product information
- "customer_data.csv" – Customer ratings and interactions
